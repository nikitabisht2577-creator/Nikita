# Rock Paper Scissors
a Simple game (Rock Paper Scissors ) using HTML, CSS, AND JavaScript.

# Features
-Play game against Computer.
-Random Computer choice generation.
- Win , lose ,tie detection.
- Live Score Update.

# Technologies used
-HTML5
-CSS
-javaScript

## How to run
-Clone this repository.
-Open `project5.html` in your browser.
-Start playing.
